# Security and Privacy

## Protected health information

This repository is intended to contain application code and documentation only. Do **not** commit patient names, MRNs, dates of birth, reports, screenshots, exported narratives, browser data, or other PHI to the repository.

The current application is static and self-contained. It does not intentionally include analytics, external JavaScript libraries, API calls, form submission endpoints, or server-side storage. Entries are processed in the browser session.

Browser/device behavior, extensions, endpoint management, screen capture, clipboard history, backups, and organizational policies remain outside the application's control. Clinical use with PHI therefore requires approval under the applicable organizational privacy/security requirements.

## Reporting changes

Before adding analytics, remote fonts, CDNs, APIs, cloud storage, telemetry, authentication, or any other network-connected feature, perform an organizational privacy/security review because those changes may materially alter the data-flow risk.
